# Infinity Digital HQ

Static site for [infinitydigitalhq.com](https://infinitydigitalhq.com), a headquarters page for [Infinity Digital Development](https://infinitydigitaldev.com).

GitHub Pages serves this repository from the `main` branch at the root. The custom domain is in `CNAME`.

- `index.html` — one-page site
- `privacy.html` — privacy policy for the site and email sent from this domain
- `styles.css` — shared styles
